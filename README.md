# 🚀 Go-To-Market (GTM) Backend – Django

This repository contains the **backend API** for the **Go-To-Market (GTM) Application**, built using **Django** and **Django Rest Framework (DRF)**.  
The backend handles authentication, business inputs, strategy generation logic, and API responses consumed by the frontend.

---

## 🛠 Tech Stack

- **Python**
- **Django**
- **Django Rest Framework**
- **JWT Authentication**
- **PostgreSQL** (configurable)
- **CORS Headers**

---

## ✨ Features

- User Authentication (Signup / Login)
- JWT-based secure API access
- Business details input (category, market, goals, etc.)
- Go-To-Market strategy generation endpoints
- Scalable REST API architecture
- Ready to integrate with AI / LLM services
